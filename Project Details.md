# 🏠 TaskSphere – AI Powered Home Service Marketplace

TaskSphere is a Full Stack Home Service Marketplace developed using **Spring Boot, Java, MySQL, HTML, CSS, and JavaScript**. The platform connects customers with verified service providers through a secure, user-friendly, and intelligent web application.

It offers AI-powered cost estimation, online booking, secure payment integration, provider management, and an administrative dashboard for efficient platform monitoring.

---

# 📌 Problem Statement

Finding trusted home service providers is often difficult due to the lack of a centralized platform. Customers face challenges such as:

- Difficulty finding verified service providers.
- No transparent pricing before booking.
- Manual booking process.
- Limited booking tracking.
- Lack of secure online payments.
- Poor communication between customers and providers.
- No centralized management system.
- No intelligent cost prediction before booking.

These issues reduce customer satisfaction and increase operational inefficiencies.

---

# 💡 Proposed Solution

TaskSphere provides a centralized digital platform that simplifies home service booking through modern web technologies.

The system provides:

- AI-based Service Cost Estimation
- Secure User Authentication using JWT
- Online Booking System
- Google Maps Integration
- Razorpay Payment Gateway
- Cloudinary Image Upload
- Provider Verification
- Booking Tracking
- Review & Rating System
- Complaint Management
- Admin Dashboard
- RESTful API Architecture
